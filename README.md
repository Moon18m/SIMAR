# SIMAR

Sistema Inteligente de Monitoreo y Administración de Refrigeración

## Descripción

SIMAR es un sistema que permite monitorear en tiempo real las condiciones de un refrigerador mediante sensores electrónicos, inteligencia artificial y una aplicación web.

## Objetivos

- Monitorear temperatura y humedad.
- Detectar apertura de puerta.
- Controlar consumo eléctrico.
- Gestionar inventario.
- Calcular la vida útil aproximada de bebidas.
- Generar alertas.
- Generar reportes.
